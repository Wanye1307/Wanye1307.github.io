# Qi Wu academic homepage

This site uses the official al-folio v1.x Jekyll starter and is published at <https://wanye1307.github.io/>.

## Editing content

- Personal information and site settings: `_config.yml`
- Homepage biography: `_pages/about.md`
- Research interests: `_pages/research.md`
- CV page data: `_data/cv.yml`
- Contact and profile links: `_data/socials.yml`
- Publications: `_bibliography/papers.bib`
- Profile photo: `assets/img/selfie.jpg`
- Downloadable CV: [Google Drive](https://drive.google.com/file/d/1iiDKsqKjID4GVzjJ7LyvH2ZojxbXl8po/view?usp=drive_link)

The separate personal blog remains available at <https://wanye1307.github.io/blog/>.

## Deployment

Pushing the source to the `main` branch runs `.github/workflows/deploy.yml`. The workflow builds the Jekyll site and publishes the generated output to the `gh-pages` branch.
